# Roadmap

This is direction, not a promise or release schedule. The
[public roadmap](https://github.com/users/junlov/projects/4) is the source for individual items,
status, and the Now / Next / Later Horizon field. Issues carry MVP, Release 1, or Release 2
milestones and job labels. This page is a short orientation, not a second backlog.

## Now: MVP

Make the runner screens and first-run setup usable, improve Garmin sync and run history,
explain plan changes, connect read-only MCP clients, and make self-hosting and contributing
approachable. Validate the merged experience against all five job stories.

## Next: Release 1

Improve data portability and resilience: backup, restore and export, run-file imports,
and reading the current week offline.

## Later: Release 2

Deepen training review and continuity: effort ratings and notes, run classification and
match corrections, moving workouts, interval repeat blocks, and starting a new race plan
after finishing the current one.
